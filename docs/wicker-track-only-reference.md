# Wicker Man: track-only reference revision

The earlier timber lattice did not match the user's intended style. `--track-only`
rebuilds the same 98.9 m HP1–LP1–HP2 section from the pinned maintenance-built
park, so none of the rejected track frames enter the replacement world.

The three new user screenshots show a stepped, narrow timber deck, light wooden
fence edges and vertical trapdoor faces. The implementation uses oak slab edges,
spruce slab middle, paired oak fences, and outward-facing oak trapdoors at roughly
2 m intervals. These are visually interpreted vanilla choices. They are not a
claim of pixel-identical reconstruction or confirmation of every screenshot block.
The deck is three sampled metre cells wide. Raster curves may widen at corners.
Fences have integer block placement; half-height deck transitions can leave a half
block of attachment offset. No logs, footings, diagonal braces, ground-reaching
posts or under-deck ties are generated by this mode.

Plan XY and the three replayed printed levels are unchanged. Heights retain the
existing provisional smooth interpolation and half-block rounding; banking is
unmeasured. Only the existing section is reconstructed. The remaining 674.7 m
of the source line stays in the park as the previous coloured plan guides.
The open plan line is not automatically closed and no train system is added.

```sh
python -m voxel_mapper.timber_track_world \
  --base-directory PATH/maintenance-built \
  --markings-path PATH/source-markings.json \
  --pdf-path PATH/original-landscape.pdf \
  --output FRESH-DIRECTORY --allow-provisional --track-only
```

Source and base checksums are retained from `wicker-track-timber-style.json`.
Native checks verify slab tops and centre-strip air; the deck-side fences are
intentionally outside that strip. Existing park structures and terrain are
preserved. The downloaded world uses a distinct track-only level name.

The default command without `--track-only` retains the previous support-inclusive
prototype for reproducibility. It is not used for this replacement delivery.
