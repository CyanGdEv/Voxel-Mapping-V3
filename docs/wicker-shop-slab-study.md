# 1:1 native slab review

Following the request to focus on 1:1, the shop package builder now exports only
the one-block-per-source-metre world. The optional `--slabs` mode samples the
same pinned source geometry at half-metre intervals internally; it does not
enlarge the building or change the world scale.

Roof and canopy occupancy selects native dark-oak bottom or top slabs. Mixed
upper/lower samples and wall/roof aliases keep full blocks. Walls retain the
illustrative spruce palette. A complete boundary and roof-step closure is
computed before material conversion; full-block doorway apertures then preserve
two-block clearance. These remain display estimates, not measured thickness.

The final main-shell blocks are expanded into their actual half-height occupancy
for the outside-air flood. Slabs occupy four half-cells, rather than being
treated as solid cubes. Door apertures and the floor are sealed for that test
only. Native export cold-reopens and verifies both slab types and every other
written block/air cell.

The reproduced assembly contains 578 block positions: 151 bottom slabs,
111 top slabs, 148 full dark-oak blocks and 168 spruce blocks. All 5,040
tested interior half-cells are unreachable from outside with doors sealed.
The preview renders the actual top/bottom slab extents from both sides.

Fences are already supported by the exporter, but are reserved for source-backed
posts and rails. No canopy post dimensions have been recovered; adding fences
as gap fillers would invent those elements. The suggested “brown cushion”
block is unspecified, so this review keeps the established brown timber palette.
Materials are illustrative, and geographic placement remains withheld.
