# Conditional 3D design massing

Planning pilots and automatic document collections now export actual local 3D
row-group envelopes from visible Design & Access Statement dimensions. Open
`design-massing.html` to rotate, zoom and compare alternatives. Each alternative
also has a GLB model, a source-linked building specification, a mesh receipt and
a static SVG view. These are unplaced design hypotheses with explicit assumptions.

The supported prose describes two rows or lines of portacabins/containers, their
length and width, an eaves height and an ambiguous distance “apart”. Original
text blocks and line order bound paragraph joins. Exact original trace/character
inventories, glyph screens, native geometry, state context and source hashes are
retained. Unrelated text is not joined, hidden or incomplete text withholds
dimensions, and conflicting paired-row paragraphs remain unresolved. The parser
does not claim general architectural language understanding.

The Woodcutters SMD/2024/0136 Design & Access Statement, dated 6 March 2024, page 7
section 4.2, supplies two rows 35.85 m long and 2.5 m wide, with 2.5 m eaves height
and a distance of 8.05 m “apart”. Two interpretations are retained:

| Interpretation | Clear distance between rows | Overall envelope |
| --- | --- | --- |
| Clear gap | 8.05 m | 35.85 × 13.05 × 2.5 m |
| Row-centre separation | 5.55 m | 35.85 × 10.55 × 2.5 m |

Neither interpretation is selected. The claimed 472 m² footprint is useful
context but does not certify the spacing endpoints. Each row is one solid group
envelope; it is not split into individual cabins. Three printed 40 ft units would
span 36.576 m, which does not equal the prose row length. The model preserves
these source distinctions rather than repairing them to fit.

The statement's approximately 5.70 m domed ridge, heritage statement's approximate
5.5 m overall height and officer report's 5.4 m height remain source claims with
different roles and unresolved correspondence. No newest-document rule selects
a physical height. Ridge values alone do not define a dome profile, so the model
omits the canopy. Openings, walls, individual containers, paths and plaza shapes
are not invented. The display has an assumed local ground zero, not a surveyed
finished level or geographic position.

The original prose PDF uses an unembedded WinAnsi font alongside an unrelated
embedded font with the same name. A restricted text-operator adapter binds an
original direct font resource to the exact ASCII text, glyph inventory and
origins before replaying the unchanged source dictionary. It keeps the existing
raster thresholds. It records that the font program is unembedded and appearance
across renderers is unverified. Forms, ambiguous overprints, unsupported text
positioning or encoding retain the existing visibility hold.

A separate section-cut detector retains exact straight source connectors between
explicit source enclosures containing repeated visible letter labels. It does
not snap endpoints, bridge gaps or assign numeric elevation indices to A-A/B-B.
Current Woodcutters floor/section sheets supply no supported cut topology; that
individual-component correspondence remains unresolved. Group design massing
does not promote it to a verified link.

Per-page narrative, source-cut and review budgets are bounded and lower-only.
Incomplete source text cannot supply a successful claim. Geometry limits outside
the supported massing range become explicit holds. Budget exhaustion clears
partial alternatives, cancellation propagates, duplicate pages deduplicate and
stale/conflicting receipts are rejected. Pilot and collection contracts pin the
font adapter, extractors, specification builder, extrusion kernel and exporter.
Recursive quotas and output hashes cover the actual nested GLB/spec/mesh exports.
Verified restart retains the same evidence and alternatives.

This creates no accepted park geometry, reviewed training label or neural weight
update. The next geometric work is recovering the actual canopy profile and
openings, then resolving plan alignment, ground levels and supported path/plaza
boundaries. The source replay is development evidence, not an independent
accuracy or unseen-area benchmark.
