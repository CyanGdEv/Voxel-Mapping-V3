All baseline feature materials, rock/fence columns, ride guides, 221 visible queue-area cells and spawn are retained. Existing features take precedence at drawing overlaps; outlines can consequently be interrupted. No resource limits are increased.

Six manually raster-traced wing/annex sections, a courtyard polygon and four passage proposals are reused from the earlier courtyard study. These are approximate source traces, not newly accepted native CAD polygons. Blue marks building boundaries; stone bricks mark the courtyard and passage floor display default. Interiors and heights are not reconstructed.

Correspondences belong to the same building and are not independent surveyed controls. This is a provisional drawing-to-drawing preview join; production geographic placement and training eligibility remain false.
